# mangalib-duo
Double-Page Reader for Mangalib. Read Manga as a Two-Page Spread.

UserScript для чтения манги на **MangaLib** в двустраничном режиме.

## Установка (нужен менеджер скриптов для вашего браузера)
   
[![Установить скрипт](https://img.shields.io/badge/Установить_скрипт-v2.9.1-f59e0b?style=for-the-badge)](https://raw.githubusercontent.com/kakosina/mangalib-duo/main/mangalib-duo.user.js)

## Возможности

- **Постраничный разворот:** ровно 2 страницы на экране без вертикальной ленты.
- **Выбор стороны первой страницы:** манга или комикс.
- **Обложка отдельно:** сдвигает парность на 1 страницу.
- **Широкие сканы целиком:** двойные развороты автоматически открываются на всю ширину.
- **Настройки в родном меню:** встраиваются в панель настроек самой читалки и не мешают.
- **Чистый экран:** верхнее и нижнее меню скрываются при открытии главы, есть режим «На весь экран».

## Управление

- **Клик / тап справа или `→` / `Пробел`** — следующий разворот (и переход на следующую главу).
- **Клик / тап слева или `←`** — предыдущий разворот.
- **Клик / тап по центру** — показать или скрыть меню читалки.
- **Горячие клавиши (ПК):** `Alt+D` — вкл/выкл разворот, `Alt+S` — сдвиг обложки, `F` — на весь экран.

## Поддерживаемые домены
